# Yara-Rules-for-Autopsy

This repository contains YARA rules designed for use with Autopsy Digital Forensics Platform to assist in malware identification, persistence detection, and artifact triage during disk and memory analysis.

These rules are optimized for:

File system scans (NTFS, FAT, etc.)
Extracted binaries from disk images
Prefetch / LNK / shortcut artifacts
Script and macro analysis
Web artifacts and dropped payloads
Persistence mechanisms
